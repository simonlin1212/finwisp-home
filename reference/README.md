# Prototype reference

`finwisp-2026-09/` contains a small whitelisted subset of the author's earlier private prototype, “Finwisp,” a Chinese-language desktop voice research assistant written in September 2026. Its git commits are dated September 18–20, with further uncommitted work through September 29.

These files are preserved verbatim and kept read-only for provenance and porting reference. They are not built, tested, or run by this project. Chinese UI strings in this directory belong to that earlier prototype.

See [Provenance](../docs/PROVENANCE.md) for the reused files and exclusions, and [Before and after](../docs/BEFORE_AFTER.md) for the differences between the prototype and Finwisp Home.
