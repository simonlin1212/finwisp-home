# How Kiro is used on this project (AWS Builder mini challenge)

Record every Kiro session that changes code in `docs/KIRO_LOG.md` (date SGT, spec/task, what Kiro generated, what a human changed, tests run). Work spec-first from `.kiro/specs/`. Mark a task done only when `npm test`, `npm run typecheck` and `npm run web:build` pass. Do not push, publish, or create cloud resources from Kiro sessions.
